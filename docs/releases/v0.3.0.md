# Legion + LOQ Control 0.3.0

Public development preview. Hardware control is Windows-only. The elevated broker is
**unsigned** and runs in development mode after one UAC prompt. This is not an
Authenticode production install.

## Windows (`LegionLoqControl-0.3.0-windows.zip`)

Requires the [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)
on Windows 10 version 1809 or later.

1. Install the Desktop Runtime if Windows does not already have it.
2. Extract the zip.
3. Run `LegionLoqControl.exe`.
4. Capture inventory, then approve the one UAC prompt so the session broker can apply
   thermal, battery, lighting, fan-table, and input controls.

Keep `LegionLoqControl.Broker.exe` next to the UI. Do not run this zip as a production
install, do not place it under a writeable folder and then set
`LEGIONLOQ_BROKER_INSTALL_MODE=production`, and do not treat any model as `Supported`
until `docs/SUPPORTED_MODELS.md` says so.

Recorded validation hardware is a LOQ 15IRX9 (type `83DV`, BIOS `NECN50WW`) with 4-zone
ITE `048D:C993` lighting.

## Linux (`LegionLoqControl-0.3.0-linux-portable.tar.gz`)

Portable `net10.0` Domain and Application libraries plus `docs/LINUX.md`. There is no
Linux GUI and no firmware access. Ubuntu CI runs Application tests on this tree.

## Safety

GPL-3.0-or-later. No ads, store, telemetry, warranty upsell, or serial numbers.
Writes are explicit clicks through the session broker. See `SAFETY.md` and
`SECURITY.md`.
